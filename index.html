Why it exists

Real incidents.
Right now.

Every field in the spec was shaped by something that actually happened. Not theoretical — production systems, real damage.

Fintech · Series B
"An agent sent 400 emails to customers. Nobody told it to."

Agent inherited full service account credentials. No scope separation. One blockActions rule would have stopped it.

missing: rules.blockActions
Healthcare SaaS · Security team
"We can't ship agents to prod until we have an audit trail."

84% of orgs can't pass a compliance audit on agent behavior. AgentPassport gives security teams what they need to say yes.

missing: identity + audit
DevOps startup · AWS bill
"A DevOps agent created recursive clusters. $12k before anyone noticed."

No spend cap. No kill switch. Discovered via invoice. rules.maxSpendUsd enforced at the credential — not in agent code.

missing: rules.maxSpend
Multi-agent pipeline · YC W25
"Agent A spawned Agent B. Agent B called an API we never approved."

No standard exists for agent-spawns-agent today. delegation.chain enforces sub-agents can't exceed their parent's scope.

missing: delegation.chain
How it works

30 minutes from
zero to verified.

01
Register your org — verify your domain

DNS TXT record. Ed25519 keypair. Your key stays with you. Discovery doc publishes at /.well-known/agentpassport.json.

02
Issue a passport when you spawn an agent

Call ap.issue() with agentId, scopes, and rules. One signed token. Attach it to the x-agent-passport header.

03
APIs verify in one line — offline, under 1ms

Call verify(token). Full typed payload — org, agentId, scopes, rules. No network round trip.

04
Revoke or update rules without redeploying

rules.revoke() or rules.block(). Propagates in under 500ms. No restart. The kill switch works.

import { AgentPassport } from 'agentpassport'

const ap = new AgentPassport({
  orgId: 'acme_corp',
  signingKey: process.env.AP_KEY
})

const { token } = await ap.issue({
  agentId: 'research-agent-01',
  scopes:  ['read:crm'],
  rules:   { blockActions: ['send:email'] },
  ttl:     '1h'
})

headers['x-agent-passport'] = token
import { verify } from 'agentpassport'

const p = await verify(
  req.headers['x-agent-passport']
)

// p.org       → 'acme_corp'
// p.agentId   → 'research-agent-01'
// p.scopes    → ['read:crm']
// p.rules     → { blockActions: [...] }

if (!p.scopes.includes(scope)) {
  return res.status(403).json({ error: 'denied' })
}
// <1ms · offline · no round trip
import { RulesClient } from 'agentpassport'

const rules = new RulesClient(process.env.AP_KEY)

// Kill one agent instantly
await rules.revoke('research-agent-01')

// Block across ALL org agents
await rules.block({ action: 'send:external-email' })

// Propagates in <500ms. No redeploy.
