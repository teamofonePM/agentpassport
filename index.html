Why ACF exists

Real incidents.
Right now.

Every field in the ACF spec was shaped by something that actually happened in production.

Fintech · Series B
"An agent sent 400 emails to customers. Nobody told it to."

No scope separation. Agent inherited full credentials. One block_actions rule would have stopped it.

missing: rules.block_actions
Healthcare SaaS · Security team
"We can't ship agents to prod until we have an audit trail."

84% of orgs can't pass a compliance audit on agent behavior. ACF gives security teams what they need to say yes.

missing: identity + audit
DevOps startup · AWS bill
"A DevOps agent created recursive clusters. $12k before anyone noticed."

No spend cap. No kill switch. rules.max_spend_usd enforced at the credential — not in agent code.

missing: rules.max_spend_usd
Multi-agent pipeline · YC W25
"Agent A spawned Agent B. Agent B called an API we never approved."

No existing standard covers agent-spawns-agent. delegation.chain enforces sub-agents can't exceed parent scope.

missing: delegation.chain
How it works

30 minutes from
zero to verified.

01
Register your org

DNS TXT record. Ed25519 keypair. Your key stays with you. Discovery doc at /.well-known/acf.json.

02
Issue a credential when you spawn an agent

Call acf.issue() with agentId, scopes, and rules. One signed token. Attach to x-acf-token header.

03
APIs verify in one line — offline, under 1ms

Call verify(token). Full typed payload — org, agentId, scopes, rules. No network round trip.

04
Revoke or update rules without redeploying

rules.revoke() or rules.block(). Propagates in under 500ms. No restart. The kill switch works.

import { ACF } from 'acf-token'

const acf = new ACF({
  orgId:      'acme_corp',
  orgDomain:  'acme.com',
  signingKey: process.env.ACF_PRIVATE_KEY
})

const { token } = await acf.issue({
  agentId: 'research-agent-01',
  scopes:  ['read:crm'],
  rules:   { blockActions: ['send:email'] },
  ttl:     '1h'
})

headers['x-acf-token'] = token
import { verify } from 'acf-token'

const cred = await verify(
  req.headers['x-acf-token']
)

// cred.org       -> 'acme_corp' (domain-verified)
// cred.agentId   -> 'research-agent-01'
// cred.scopes    -> ['read:crm']
// cred.rules     -> { blockActions: ['send:email'] }

if (!cred.scopes.includes(scope)) {
  return res.status(403).json({ error: 'denied' })
}
// offline · under 1ms · no round trip
import { RulesClient } from 'acf-token'

const rules = new RulesClient(process.env.ACF_KEY)

// Kill one agent instantly
await rules.revoke('research-agent-01')

// Block across ALL org agents
await rules.block({ action: 'send:external-email' })

// Propagates in under 500ms. No redeploy.
